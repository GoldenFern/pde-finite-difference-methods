Numerical Solution of Differential Equations (MATH3808-2)

This repository contains the reports, code, and numerical results of two undergraduate course projects. The first project compares several numerical methods for the two-dimensional Poisson equation. The second project studies the stability and numerical behavior of several finite difference schemes for the convection equation.

## Project 1: Comparison of Numerical Solution Methods for the Poisson Equation Using the Five-Point Difference Scheme

The project solves the two-dimensional Poisson equation on a rectangular domain with homogeneous Dirichlet boundary conditions. The test problem is

$$
\Delta u = -2\pi^2\sin(\pi x)\sin(\pi y),\qquad u=0\ \text{on}\ \partial\Omega,
$$

with the exact solution $u=\sin(\pi x)\sin(\pi y)$.

The report compares the following numerical methods:

- Five-point finite difference scheme
- Discrete sine transform (DST)
- LU decomposition
- Jacobi iteration (explicit double loop)
- Jacobi iteration accelerated by `scipy.signal.convolve2d`
- Gauss-Seidel iteration
- SOR iteration

The experiments measure the runtime, mean absolute error, and maximum error of each method on different grids. The methods are then extended to nonhomogeneous Dirichlet boundary conditions.

Main conclusions: DST is significantly faster than the other methods. DST and LU decomposition produce the same discrete solution, and the error decreases as $O(h^2)$ under grid refinement. Among the iterative methods, the convolution-accelerated Jacobi method is much faster than the explicit loop implementation.

## Project 2: Comparative Experiments on the Stability and Numerical Effects of Finite Difference Schemes

The project solves the one-dimensional convection equation

$$
u_t+au_x=0,
$$

with a unit step function as the initial condition. The spatial step is $h=0.1$, the time step is $\tau=0.08$, the grid ratio (CFL number) is $\lambda=\tau/h=0.8$, and the solution is computed up to $t=4.0$ with advection speeds $a=1,2,4$.

The report implements and compares four finite difference schemes:

- Upwind scheme
- Beam-Warming scheme
- Lax-Friedrichs scheme
- Lax-Wendroff scheme

The experiments compute the discrete $L^2$ error and use amplification factors and modified equations to analyze the convergence conditions of each scheme, as well as the dissipation and dispersion effects near the discontinuity.

Main conclusions: all four schemes converge for $a=1$; only the Beam-Warming scheme converges for $a=2$; all four schemes diverge for $a=4$. The upwind and Lax-Friedrichs schemes are dominated by dissipation, while the Beam-Warming and Lax-Wendroff schemes show pronounced dispersive oscillations near the discontinuity.

## Requirements and Usage

Python 3.9 or newer is required. Install the dependencies with

```bash
python -m pip install -r requirements.txt
```

Run Project 1:

```bash
python "Project1/微分方程数值解 - Project1.py"
```

The full experiment in Project 1 loops over many grid sizes and several iterative methods, so it takes a long time. To do a quick check, reduce the `n_values` range passed to `time_error_analysis` in `main()`.

Run Project 2:

```bash
python "Project2/差分格式求解代码.py"
```

Project 2 writes 12 PNG figures to the current directory. The results from the original run are kept in `Project2/数值结果/`.

### Font Note

The plotting code in Project 1 originally used `times+simsun.ttf` for Chinese and English labels. The font file is not included in this repository. The code now falls back to system fonts when the file is missing. If Chinese labels appear as empty boxes, install a CJK font or place `times+simsun.ttf` next to the script.
